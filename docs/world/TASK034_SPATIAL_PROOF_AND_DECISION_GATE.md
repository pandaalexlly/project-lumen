## 6. Complete state/observer model

### 6.1 Exhaustive rule factorization

These rules cover every combination, rather than pretending a finite example list enumerates all continuous views and stances.

For actual q in {A,B,C}:

- U = placements whose participating envelopes the actual player view would observe; q in U means current observation, another element means candidate exclusion.
- I contributes {A}, {C}, or empty when off. R contributes {B} or empty.
- Current hold = q in the union of those observation sets.
- Start with alternatives {A,B,C} minus q. Remove observed alternatives, any occupied/unsafe complete candidate, and any candidate invalid for the passenger's body/camera.
- A partial/unsafe departure veto makes the transition unavailable; it is not an observer.
- A hold prevents transition even with legal alternatives. Actual current observation rearms.
- Otherwise a mature, unspent release chooses one remaining complete alternative; none means wait without consuming it.
- After a successful change, mark spent. Empty-position sight, clue reads and elapsed time do not rearm.
- A full supported player maps with the object; a safely independent player stays. Never discard a passenger to admit a candidate.

| Current q | I aimed A | I aimed C | R on |
| --- | --- | --- | --- |
| A | Holds/rearms A | Excludes C | Excludes B |
| B | Excludes A | Excludes C | Holds/rearms B |
| C | Excludes A | Holds/rearms C | Excludes B |

This factorization includes unreachable-at-one-moment arrangements without silently inventing controls at C. Source changes require the player's actual fixed access. A player left inside can reconfigure sources while C is empty; a rider outside cannot remotely toggle them.

### 6.2 Table conventions

L = legal alternatives before current hold/release-budget gates. Ex = excluded alternatives and cause. Under TASK-034.3/S2, P=H means a P2 E/view-range pose with **all participating body/payload geometry** concealed, including direct silhouettes; indirect shadows do not add an observation requirement. P=H replaces the old nominal-only pose; P=F means a south-facing fixed control/apron view with all three body envelopes hidden. Other P entries name observed placements. “Ready” includes the normal release/grace intervals and safety revalidation; it is not a UI state. Presentation is assessed separately, never added to U or L.

Rearm codes: a = see actual A or I→A; b = see actual B or R→B; c = see actual C or I→C. Seeing a candidate never suffices.

Recovery codes:

- **At A:** hold through actual sight/I, then prepare while keeping a member visible.
- **Back A from B:** fixed path to I/R; rearm B using R; aim I→C; release R and player view with A hidden. A only.
- **Back A from empty C:** fixed I access; I→C rearms; R excludes B; I off and P=F. A only.
