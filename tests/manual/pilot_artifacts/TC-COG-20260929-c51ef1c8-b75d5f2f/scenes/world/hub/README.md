# Central Facility Hub

`operations_atrium.tscn` is the shared Operations Atrium, instanced south of the Awakening Chamber at `(0, 0, 6)`. Run the project (F5) to enter through the existing opening experience.

The chamber's service-control signal supplies the existing bulkhead motor and three hub circulation lights. The player walks into the hub without a scene change and can return freely. `sealed_wing_approach.tscn` provides collision and visible security hardware for the four future wings; their machinery is passive scenery. No wing gameplay exists yet.

See [the hub foundation](../../../docs/world/CENTRAL_HUB_FOUNDATION.md) for coordinates, object purposes, validation, and playtest questions.
