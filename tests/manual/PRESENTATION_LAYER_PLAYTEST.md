# Vertical Slice Presentation Playtest

Start with F5 and verify the following without using the editor:

- The main menu clearly offers one primary action and communicates the controls.
- Each gameplay scene briefly shows its correct room identifier without
  covering a puzzle object or the crosshair area.
- A focused Beam switch or recovery console shows one `[E]` prompt; looking
  away removes it immediately.
- The Discovery, Destination, Combined, and Field switches expose their glowing
  control faces without a decorative panel covering the indicator.
- Power switches still toggle Beam state, aim switches still redirect it, and
  Combined recovery still preserves Beam OFF.
- Event notices are readable but do not reveal a solution before the associated
  world event occurs, and do not persist into the next scene.
- The ending supports Field Site revisit with `R` or the button and returns to
  the main menu with the secondary button.

Record whether room titles, prompts, or notices feel distracting; whether the
menu-to-world transition feels coherent; and which silent event most strongly
needs an eventual sound cue.
